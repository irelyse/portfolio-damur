# Free Electrician Website Template



Built with React 19, Vite and Tailwind CSS v4. This is the same file that
renders the live preview on the site — not a cut-down version of it.

    npm install
    npm run dev

## Where things are

Everything is in `src/App.jsx`. It is one file on purpose: each section is a
small component near the bottom, and the content each one renders is declared
as a plain array at the top of the file. Change the arrays to change the site.
The only import is React, so there is nothing else to learn before you edit it.

Fonts are declared in `index.html` and mapped to `--font-tpl-body` and
`--font-tpl-serif` in `src/index.css`.

## The hero image

`public/hero.webp` is **AI-generated placeholder artwork**, not a photograph of
any real premises, and it is deliberately atmospheric rather than a picture of
staff or customers — no faces, no signage, nothing that could be mistaken for a
real business. It ships inside this ZIP rather than being loaded from our
servers, so nothing here depends on spicerdesigns.com staying up.

Swap it for your own photography before launch. The path is set once, as
`const HERO` at the top of `src/App.jsx`.
